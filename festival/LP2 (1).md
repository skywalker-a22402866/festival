## Modelo base assumido

Este guia assume que já existem modelos parecidos com estes:

```python
# models.py

from django.db import models


class Banda(models.Model):
    nome = models.CharField(max_length=100)

    def __str__(self):
        return self.nome


class Dia(models.Model):
    data = models.DateField()

    def __str__(self):
        return str(self.data)


class Palco(models.Model):
    nome = models.CharField(max_length=100)
    capacidade = models.IntegerField()

    def __str__(self):
        return self.nome


class Concerto(models.Model):
    banda = models.ForeignKey(Banda, on_delete=models.CASCADE)
    palco = models.ForeignKey(Palco, on_delete=models.CASCADE)
    dia = models.ForeignKey(Dia, on_delete=models.CASCADE)
    hora = models.TimeField()

    def __str__(self):
        return f"{self.banda} - {self.dia} - {self.hora}"
```

# 1. Modelação de estilos musicais

## Objetivo

Permitir associar **um ou mais estilos musicais** a cada banda.

Exemplos:

- Alessi Rose → pop
- Florence + The Machine → rock, pop
- Buraka Som Sistema → electronic
- Palaye Royale → punk, rock

---

## 1.1. Alterar `models.py`

```python
# models.py

class EstiloMusical(models.Model):
    nome = models.CharField(max_length=100, unique=True)
    bandas = models.ManyToManyField(
        Banda,
        related_name="estilos",
        blank=True
    )

    def __str__(self):
        return self.nome
```

## O que este bloco faz

Cria o modelo `EstiloMusical`.

A relação é `ManyToManyField` porque:

- um estilo pode ter várias bandas;
- uma banda pode ter vários estilos.

Com `related_name="estilos"`, consegues fazer:

```python
banda.estilos.all()
```

Isto devolve todos os estilos associados a uma banda.

---

## 1.2. Criar e aplicar migrações

```bash
python manage.py makemigrations
python manage.py migrate
```

## O que este bloco faz

- `makemigrations`: cria o ficheiro de migração com as alterações aos modelos.
- `migrate`: aplica essas alterações à base de dados.

---

## 1.3. Registar no admin

```python
# admin.py

from django.contrib import admin
from .models import Banda, Dia, Palco, Concerto, EstiloMusical


@admin.register(EstiloMusical)
class EstiloMusicalAdmin(admin.ModelAdmin):
    list_display = ("nome",)
    search_fields = ("nome",)
    filter_horizontal = ("bandas",)


admin.site.register(Banda)
admin.site.register(Dia)
admin.site.register(Palco)
admin.site.register(Concerto)
```

## O que este bloco faz

Permite gerir estilos musicais no admin.

O `filter_horizontal = ("bandas",)` melhora a interface para escolher várias bandas associadas a cada estilo.

# 2. Página de estilos

## Objetivo

Criar uma página que liste os estilos musicais e, para cada estilo, mostre as bandas associadas.

Exemplo:

```text
Rock
- Florence + The Machine
- Palaye Royale

Pop
- Alessi Rose
- Florence + The Machine
```

---

## 2.1. Criar a view

```python
# views.py

from django.shortcuts import render
from .models import EstiloMusical


def estilos_view(request):
    estilos = EstiloMusical.objects.prefetch_related("bandas").order_by("nome")

    return render(
        request,
        "festival/estilos.html",
        {"estilos": estilos}
    )
```

## O que este bloco faz

Vai buscar todos os estilos musicais e as bandas associadas a cada estilo.

O `prefetch_related("bandas")` é usado porque `bandas` é uma relação ManyToMany. Isto evita muitas queries repetidas à base de dados.

---

## 2.2. Criar a rota

```python
# urls.py da app

from django.urls import path
from . import views

urlpatterns = [
    path("estilos/", views.estilos_view, name="estilos"),
]
```

## O que este bloco faz

Cria a rota:

```text
/estilos/
```

E associa essa rota à view `estilos_view`.

---

## 2.3. Criar o template

Criar o ficheiro:

```text
templates/festival/estilos.html
```

Código:

```django
{% extends "base.html" %}

{% block content %}
<h1>Estilos Musicais</h1>

{% for estilo in estilos %}
    <h2>{{ estilo.nome }}</h2>

    <ul>
        {% for banda in estilo.bandas.all %}
            <li>
                {{ banda.nome }}
                {% include "festival/includes/estilos_banda.html" with banda=banda %}
            </li>
        {% empty %}
            <li>Sem bandas associadas.</li>
        {% endfor %}
    </ul>
{% empty %}
    <p>Ainda não existem estilos musicais.</p>
{% endfor %}

{% endblock %}
```

## O que este bloco faz

Mostra todos os estilos e, dentro de cada estilo, lista as bandas associadas.

O `{% empty %}` serve para mostrar uma mensagem caso não existam dados.

# 4. Mostrar estilos depois do nome da banda

## Objetivo

Nas páginas de estilos, dias e palcos, mostrar os estilos musicais depois do nome da banda.

Exemplo:

```text
Florence + The Machine (rock pop)
Buraka Som Sistema (electronic)
Palaye Royale (punk rock)
```

---

## 4.1. Criar template reutilizável

Criar o ficheiro:

```text
templates/festival/includes/estilos_banda.html
```

Código:

```django
{% if banda.estilos.all %}
    (
    {% for estilo in banda.estilos.all %}
        {{ estilo.nome }}{% if not forloop.last %} {% endif %}
    {% endfor %}
    )
{% endif %}
```

## O que este bloco faz

Mostra todos os estilos de uma banda entre parênteses.

Exemplo:

```text
Florence + The Machine (rock pop)
```

---

## 4.2. Usar o include nos templates

Sempre que encontrares isto:

```django
{{ banda.nome }}
```

Troca por isto:

```django
{{ banda.nome }}
{% include "festival/includes/estilos_banda.html" with banda=banda %}
```

## O que este bloco faz

Mostra o nome da banda e, logo a seguir, os seus estilos musicais.

---

## 4.3. Exemplo na página de dias

Se estiveres a listar concertos:

```django
{% for concerto in concertos %}
    <p>
        {{ concerto.banda.nome }}
        {% include "festival/includes/estilos_banda.html" with banda=concerto.banda %}
        - {{ concerto.hora }}
    </p>
{% endfor %}
```

## O que este bloco faz

Mostra a banda de cada concerto com os estilos associados.

---

## 4.4. Exemplo na página de palcos

```django
{% for concerto in palco.concertos.all %}
    <p>
        {{ concerto.banda.nome }}
        {% include "festival/includes/estilos_banda.html" with banda=concerto.banda %}
        - {{ concerto.hora }}
    </p>
{% endfor %}
```

## O que este bloco faz

Mostra os concertos associados a um palco, incluindo os estilos de cada banda.

---

## 4.5. Melhorar queries nas views

Sempre que listares concertos com banda e estilos, podes usar:

```python
concertos = Concerto.objects.select_related(
    "banda",
    "palco",
    "dia"
).prefetch_related(
    "banda__estilos"
)
```

## O que este bloco faz

O `select_related` otimiza relações `ForeignKey`.

O `prefetch_related` otimiza relações `ManyToMany`.

Neste caso:

- `banda`, `palco` e `dia` são ForeignKey;
- `banda__estilos` é ManyToMany.

# 5. Edição da capacidade dos palcos

## Objetivo

Implementar o botão de editar capacidade de um palco.

É necessário criar:

- form;
- view;
- template;
- url.

---

## 5.1. Criar o form

```python
# forms.py

from django import forms
from .models import Palco, Concerto


class PalcoCapacidadeForm(forms.ModelForm):
    class Meta:
        model = Palco
        fields = ["capacidade"]
```

## O que este bloco faz

Cria um formulário baseado no modelo `Palco`, mas permite editar apenas o campo `capacidade`.

---

## 5.2. Criar a view

```python
# views.py

from django.shortcuts import render, redirect, get_object_or_404
from .models import Palco
from .forms import PalcoCapacidadeForm


def editar_capacidade_palco(request, palco_id):
    palco = get_object_or_404(Palco, id=palco_id)

    form = PalcoCapacidadeForm(
        request.POST or None,
        instance=palco
    )

    if form.is_valid():
        form.save()
        return redirect("palcos")

    return render(
        request,
        "festival/editar_capacidade_palco.html",
        {
            "form": form,
            "palco": palco
        }
    )
```

## O que este bloco faz

- Vai buscar o palco pelo `id`;
- cria um formulário ligado a esse palco;
- se o formulário for válido, guarda a nova capacidade;
- redireciona para a página dos palcos.

O `instance=palco` é essencial porque indica que estás a editar um objeto existente.

---

## 5.3. Criar a rota

```python
# urls.py

path(
    "palcos/<int:palco_id>/editar-capacidade/",
    views.editar_capacidade_palco,
    name="editar_capacidade_palco"
),
```

## O que este bloco faz

Cria uma rota para editar a capacidade de um palco específico.

Exemplo:

```text
/palcos/1/editar-capacidade/
```

---

## 5.4. Criar o template

Criar o ficheiro:

```text
templates/festival/editar_capacidade_palco.html
```

Código:

```django
{% extends "base.html" %}

{% block content %}
<h1>Editar capacidade do palco</h1>

<h2>{{ palco.nome }}</h2>

<form method="post">
    {% csrf_token %}
    {{ form.as_p }}

    <button type="submit">Guardar</button>
</form>

<a href="{% url 'palcos' %}">Voltar</a>
{% endblock %}
```

## O que este bloco faz

Mostra o formulário para editar a capacidade de um palco.

O `{% csrf_token %}` é obrigatório em formulários POST no Django.

---

## 5.5. Ligar o botão na página dos palcos

Na página onde listas os palcos, adicionar ou corrigir o botão:

```django
<a href="{% url 'editar_capacidade_palco' palco.id %}">
    Editar capacidade
</a>
```

## O que este bloco faz

Faz com que o botão envie o utilizador para a página de edição da capacidade daquele palco específico.

# 6. Alterações na edição de concertos

## Objetivo

Alterar a edição de concertos para permitir editar também:

- palco;
- dia.

---

## 6.1. Alterar ou criar o form de concerto

```python
# forms.py

class ConcertoForm(forms.ModelForm):
    class Meta:
        model = Concerto
        fields = [
            "banda",
            "palco",
            "dia",
            "hora",
        ]
```

## O que este bloco faz

Permite editar os campos principais do concerto, incluindo `palco` e `dia`.

Se o formulário já existir, provavelmente só tens de garantir que inclui:

```python
"palco",
"dia",
```

---

## 6.2. Criar ou alterar a view de edição

```python
# views.py

from .models import Concerto
from .forms import ConcertoForm


def editar_concerto(request, concerto_id):
    concerto = get_object_or_404(Concerto, id=concerto_id)

    form = ConcertoForm(
        request.POST or None,
        instance=concerto
    )

    if form.is_valid():
        form.save()
        return redirect("concertos")

    return render(
        request,
        "festival/editar_concerto.html",
        {
            "form": form,
            "concerto": concerto
        }
    )
```

## O que este bloco faz

Permite editar um concerto existente.

O `instance=concerto` indica que o formulário está associado ao concerto que já existe.

---

## 6.3. Criar ou confirmar a rota
